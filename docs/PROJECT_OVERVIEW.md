## 1. 这是什么

**AgentForge 是一个「AI Agent 编排 + 企业治理」一体化的开源平台**，目标是把多 Agent 编排的企业级能力，落到**中小企业的业务智能化改造**上——首个落地区景是**客服 / 售后工单智能处理**。

它不是单一算法 Demo，而是一套**能放到生产环境、受治理约束、可观测、可降本**的平台基础设施。核心哲学是：

> **用治理边界约束 AI 的自动化能力**——AI 可以分类、检索、总结、起草，但所有面向客户和高风险的动作，必须在人工审核/审批后才能执行。

## 2. 双栈架构（两大能力面）

| 栈 | 是什么 | 核心能力 |
|---|---|---|
| **上层 · 多 Agent 编排引擎** | 任务编排 + 路由 + 可靠性 | DAG 任务引擎（≤50节点）、5 模型智能路由、语义缓存、三级 Memory、全链路 Trace、三层超时、四级降级、三态熔断、请求放大管控 |
| **下层 · 企业 AI 平台层** | 多租户企业治理 + 业务场景成环 | 多租户 / RBAC+声明式策略 / 配额成本治理 / 全过程审计 / Temporal 工作流 + Outbox / 检索评估与回归 / 连接器与工单写回 |

两条能力面相互配合：上层提供"AI 能做什么"的可靠性底座，下层提供"企业允许 AI 做什么"的治理边界。

## 3. 解决什么问题（企业价值）

1. **业务提效**：客服工单从"检索→生成→审批→写回"全流程 AI 辅助，AI 起草、人工把关，缩短首次响应与人工处理时间。
2. **降本**：5 模型路由（简单任务走低成本模型）+ 语义缓存，LLM 调用成本降低 **68%**，端到端延迟降低 **38%**（非商用环境基准）。
3. **生产高可靠**：三层超时 + 四级降级 + 三态熔断 + 请求放大管控 + 压测容量（~500rps/25并发，对 SME 客服留 10 倍余量）。
4. **企业合规与可控**：多租户隔离 + RBAC + fail-closed 策略 + 高危动作人工审批强制边界 + 全链路审计（回答"谁执行、为何允许"）。
5. **可观测可回查**：LLM 调用逐条 trace（模型/token/成本/延迟/租户/工单）+ dashboard 视图。

## 4. 核心亮点（为什么值得看）

- **企业治理控制面是本项目最稀缺的差异化资产**：多租户 + 策略引擎 + 配额成本 + 审计 + 质量门禁 + Outbox，整合为一致性平台——这是通用开源件（Langfuse/LiteLLM/RAGFlow/Dify）都不直接提供的层，拼装需要大量工程时间。
- **可靠性工程纵深成体系**：不是零散加固，而是从超时、降级、熔断、限流到请求放大管控的完整方法论，且超时/降级参数**基于 15000+ 请求的真实实测**。
- **工程功底扎实**：728 个自动化测试全绿、black/isort/flake8/mypy 全仓零错误、CI 多版本矩阵、完整文档体系（架构/ADR/SECURITY/性能压测/可观测/策略）。
- **务实落地**：压测器自研（零外部依赖、可复现）、可观测先做进程内闭环再留熟件接线路径（无 Docker 环境的正确取舍）。
