## 安全扫描要求
1. 检测 SQL 注入、XSS、CSRF 等常见安全漏洞
2. 检测硬编码密钥、密码、Token
3. 检测敏感信息泄露（日志中的密码、错误信息中的堆栈）
4. 检测不安全的依赖库版本
5. 每个漏洞必须引用具体的代码行
6. 按严重程度分级：critical | warning | info
7. 输出结构化 JSON 格式：
   ```json
   {
     "findings": [
       {
         "severity": "critical",
         "type": "sql_injection",
         "description": "漏洞描述",
         "file": "文件名",
         "line": 行号,
         "evidence": "相关代码片段",
         "remediation": "修复建议"
       }
     ],
     "severity": "critical|warning|info",
     "has_vulnerabilities": true,
     "summary": "安全扫描摘要"
   }
   ```
